### 🌐 Help & Community

**Have a question, bug, or feature idea?**
Overwire is free, open-source, and built with love by a **sole maintainer**. To keep development fast and focused, we coordinate all feedback and tracking through our official **GitHub repository**.

Please follow these quick guidelines before posting:

* **🐛 Found a Bug?**
  Open a **GitHub Issue** using our Bug Report template. Please include your browser version (Chrome or Firefox) and the exact matching rules or console logs so it can be isolated and fixed quickly.
* **💡 Feature Requests**
  Have an idea for a new local action, recipe, or bridge enhancement? Head to **GitHub Issues** and select the Feature Request template. *Note: Overwire is strictly a zero-account, local-first utility, so cloud syncing or remote server features are outside our architectural scope.*
* **💬 General Questions & Discussions**
  Not sure how to write a regex match, or want to discuss a custom mock setup? Please use the **GitHub Discussions** tab instead of opening an issue. It’s the perfect place for community Q&A, tips, and open-ended conversations.

👉 [**Visit the Overwire GitHub Repository**](https://github.com/proto-void/overwire)
